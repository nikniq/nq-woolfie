# Custom sound clips

Drop audio files here to replace the built-in synthesised effects. The game
looks for `<name>.mp3`, then `.ogg`, then `.wav` for each of:

alert, caught, pickup, treasure, door, win, gameover, hide, portal,
alarm, spikes, crumble, gas, fall, blade, step, bark, shoot, hit, siren

A `music.(mp3|ogg|wav)` file is looped as the background track in place of
the procedural drone.

Only use clips you have the rights to. The original Castle Wolfenstein and
Wolfenstein 3D audio is copyrighted by Muse Software / id Software and is not
included here.
